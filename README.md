# 秀丸風 背景マーカー（VS Code拡張機能）

選択範囲や指定した単語に複数色の背景色を付けられるVS Code拡張機能です。

## セットアップと実行方法

1. フォルダを展開し、ターミナルで依存パッケージをインストールします。
   ```bash
   npm install
   ```
2. VS Codeでこのフォルダを開き、**F5キー**を押すとデバッグウィンドウが起動します。

## ショートカットキー

* `Alt + M`: メニューから単語と色を選んで塗る
* `Alt + 1`: 1発で塗る（黄色）
* `Alt + 2`: 1発で塗る（緑色）
* `Alt + 3`: 1発で塗る（水色）
* `Alt + 4`: 1発で塗る（ピンク）
* `Alt + 5`: 1発で塗る（オレンジ）
* `Alt + 0`: 選択範囲またはカーソル位置の背景色を消す（消しゴム）
