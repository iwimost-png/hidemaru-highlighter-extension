# 秀丸風 背景マーカー（VS Code拡張機能）

選択範囲や指定した単語に複数色の背景マーカーを付けられるVS Code拡張機能です。
秀丸エディタのように、テキストやソースコードを読みながら気になったキーワードや文章を手軽に色分けハイライトし、一覧表示や素早いジャンプで巡回できます。

---

## 🌟 主な機能

* **複数色のマーカーハイライト**:
  * プリセット5色（🟡 黄色, 🟢 緑色, 🔵 水色, 🟣 ピンク, 🟠 オレンジ）
  * 🎨 自由なカラーコード指定（HEX, RGB, RGBA, HSL など）に対応。
  * **不透明度（濃さ）の動的調整**: 設定で不透明度を変更すると、既存のすべてのマーカーの濃さが一瞬で更新されます。
* **ワンタッチ着色**:
  * ショートカットキー1発で選択範囲やカーソル位置の単語を即座に着色。
* **メニューから柔軟に一括ハイライト＆消去**:
  * 選択範囲のみを塗る
  * 単語全体が完全一致する箇所をファイル内で一括ハイライト（日本語・英数字両対応、CRLF/LF改行正規化）
  * 部分一致する箇所を一括ハイライト
  * 大文字・小文字の違いを無視（Case-Insensitive）して一括ハイライト（単語境界を保持）
  * 任意の検索文字列を入力して一括ハイライト
  * **🧹 メニューからマーカー全消去 / 指定色消去も即座に実行可能**。
* **📋 マーカー一覧表示＆検索（リアルタイムプレビュー）**:
  * ファイル内の全マーカーを行番号・色・テキスト抜粋とともに一覧表示。
  * キーボードの上下キーで移動するだけで該当箇所へリアルタイムにスクロールプレビュー！
* **📍 マーカー間ジャンプ（次へ / 前へ）**:
  * ハイライトされた箇所へキー操作で次々にキャレットを移動・自動スクロール（ループ移動対応）。
  * 隣接したマーカーもスキップせずに順番にジャンプ。
  * **誤入力防止仕様**: 単語を選択反転させずキャレットを先頭に置くため、ジャンプ直後に文字を誤タイプしても単語が消滅しません。
* **重ね塗り・上書き**:
  * 既存のハイライトの上から別の色を塗った場合、重なった部分が新しい色に自動で切り替わります。
* **消しゴム・クリア機能**:
  * **選択範囲消しゴム**: 選択した部分だけをくり抜き消去。
  * **マーカー消去**: ハイライト上で消しゴムを押すと、そのマーカー全体を綺麗に1発消去。
  * **🧹 このファイルのマーカーを全消去（ショートカット1発 ＆ Undo復元対応）**:
    * 誤って全消去を押しても、通知の「元に戻す (Undo)」ボタンで一発で元通りに復元できます。
  * **指定色クリア**: 特定の色（例: 黄色だけ）を選んで一括消去。
  * **全ファイル全クリア**。
* **💾 ハイライトの永続化＆自動クリーンアップ**:
  * ファイルを閉じたり、VS Codeを再起動しても、付けたハイライトが自動的に復元されます。
  * **ファイル名変更（リネーム・名前を付けて保存）** にも自動追従してハイライトを引き継ぎます。
  * ファイルを削除した際はストレージから不要データを自動で安全にクリーンアップします。
* **📊 ステータスバー表示**:
  * エディタ右下に現在のファイルのマーカー件数（例: `🎨 5`）を常時表示。クリックでメニューがポップアップ。
* **マルチタブ・左右分割エディタ（Split Editor）完全同期**:
  * 同一ファイルを左右で分割表示していてもリアルタイムに同期します。
* **文字入力への高精度追従**:
  * テキストの編集、改行、削除、アンドゥ（Ctrl+Z）にもハイライト位置が安全に追従します。

## ⌨️ ショートカットキー一覧

| 機能 | Windows / Linux | macOS |
| :--- | :--- | :--- |
| **メニューから塗る・消す** | `Alt + M` | `Cmd + Alt + M` |
| **1発で塗る（🟡 黄色）** | `Alt + 1` | `Cmd + Alt + 1` |
| **1発で塗る（🟢 緑色）** | `Alt + 2` | `Cmd + Alt + 2` |
| **1発で塗る（🔵 水色）** | `Alt + 3` | `Cmd + Alt + 3` |
| **1発で塗る（🟣 ピンク）** | `Alt + 4` | `Cmd + Alt + 4` |
| **1発で塗る（🟠 オレンジ）** | `Alt + 5` | `Cmd + Alt + 5` |
| **消しゴム（選択範囲/カーソル位置）** | `Alt + 0` | `Cmd + Alt + 0` |
| **🧹 このファイルのマーカーを全消去** | `Shift + Alt + 0`<br>`Alt + C` | `Shift + Cmd + Alt + 0`<br>`Cmd + Alt + C` |
| **📋 マーカー一覧を表示・ジャンプ** | `Alt + L` | `Cmd + Alt + L` |
| **📍 次のマーカーへジャンプ** | `Alt + ]` | `Cmd + Alt + ]` |
| **📍 前のマーカーへジャンプ** | `Alt + [` | `Cmd + Alt + [` |

> **💡 ヒント**:
> * エディタ右上にある **🎨 アイコン** または右下のステータスバーをクリックすることでもメニューを呼び出せます。
> * 右クリックのコンテキストメニュー「🎨 背景マーカー（色付け）」からも全機能を利用可能です。
> * 全消去を実行した直後に表示される通知の「元に戻す (Undo)」をクリックすると、消去前のハイライトを復元できます。

## ⚙️ 設定オプション（Settings）

VS Code の設定画面（`Ctrl + ,`）で `hidemaruHighlighter` を検索して変更できます：

| 設定項目 | 型 | デフォルト | 説明 |
| :--- | :--- | :--- | :--- |
| `hidemaruHighlighter.opacity` | `number` | `0.4` | マーカーの不透明度（`0.1`: 薄め 〜 `1.0`: 完全に不透明）。変更すると既存のマーカーも即時更新されます。 |
| `hidemaruHighlighter.showStatusBarItem` | `boolean` | `true` | エディタ右下にマーカー件数アイテムを表示するかどうか |

## 🛠️ 開発・デバッグ実行方法

1. ターミナルで依存パッケージをインストールします：
   ```bash
   npm install
   ```
2. VS Codeでこのフォルダを開き、**F5キー**を押すと拡張機能開発環境（Debug Window）が起動します。
3. ビルドコマンド：
   ```bash
   npm run compile
   ```
